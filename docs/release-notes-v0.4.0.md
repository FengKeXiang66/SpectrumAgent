# v0.4.0 release notes（发布准备草稿）

本版准备将 N01 外发总闸、F06 计划批准闸与跳过/回退、TASK-07 12.8 手势联调一起交付。实现过闸记录见 TASK-07 §12 的 R49；真实 NAS / provider、安装态冒烟及发布动作待科祥执行。本段只准备文书，不修改版本配置，不生成安装包或发布记录。

## 用户可感知变化

- **N01：允许外发总闸。** 设置屏可关闭“允许外发”，关闭后对话与结果解读被拒绝，审计记录 `LLM_EGRESS_DISABLED / blocked`；导入、分割、标注与训练 MAT 等核心分析继续可用。关闭状态持久保存，重启仍关闭；重新开启后可恢复对话。开关从下一次调用生效，不主动取消已经在途的调用。
- **F06：执行前审阅计划。** 多工具轮次先展示计划卡，列出步骤、算子、标量摘要、GPU 信息和预估；单调用轮次不弹计划卡。批准后执行全部有效步骤；拒绝则零执行并结束本轮；`skip(K)` 不执行第 K 步及之后，卡片标明失效范围；`rollback(N)` 不执行前缀，从第 N 步开始执行。这里的回退是选择待执行后缀，计划批准仍保留既有逐工具人工确认。除批准外的动作记录原因，预估值不作为实测承诺。
- **12.8：从画布手势引用到标注。** 点、框、涂鸦在扩散前先存为服务会话内手势，面板显示可复制的 `g-` 引用，可在对话中引用。`add_region` 的添加、不确定、擦除共用已有超像素解析；来源为 manual，添加默认 high，也支持合法的显式置信度。未知引用会明确拒绝。
- **12.8：SAM 候选可写入草稿。** REST 与工具共用确定性服务，写入来源为 algorithm；正常分支为 medium。低于入队下限时仍按请求写入区域，置信度标为 low，摘要的 `queue_note` 带实际下限；候选由既有消费逻辑移除。助手只接收标量摘要，不接收坐标数组或完整草稿文档。

## 已知限制

1. **SLIC 选候选产品语义未定义。** 工具与 REST 均显式返回 `TOOL_NOT_IMPLEMENTED`，留待后续产品定义与 skill v2；SAM 已实现不代表 SLIC 已实现。
2. **空草稿首笔不能经工具写入。** revision=0 时工具路径受冻结 v1 schema 限制；先用画布多边形或 REST `/draft/regions` 建立首个标注，再通过工具继续编辑。工作台空草稿静态提示不替代首笔标注操作。
3. **手势精度为超像素粒度。** 按现有分割吸附，不生长；PE cube 约 185 px/超像素，精细边界需 polygon 重画。重分割后同一手势可能命中不同超像素。
4. **gesture ref 仅当前服务会话有效。** 重启服务后引用失效，不写入 DB 或草稿文档；已写入区域保存的是具体几何。重新引用前需重新采集手势。
