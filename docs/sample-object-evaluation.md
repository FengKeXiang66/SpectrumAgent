# 实物级派生报告（第一阶段）

本阶段为统一分类 experiments 增加显式的实物定义及报告，不重训，不改原像元指标，不修改 Study 的候选、评分或排名。旧 modeling 的按图真值多数票不作为本协议的真值来源。

## 用户流程

1. 在对话打开已完成的实验报告，展开“实物评价 → 声明或调整实物定义”；也可以说“查看实验 <编号> 的实物级报告”。
2. 明确选择 `IMAGE`（一图一物）、`MAPPED`（完整分组表，多图一物）、`MIXED`（一图多物／混合材质，不适用）。没有默认模式，不从文件名、缺省 sample_id、batch 或 NPZ groups 推断实物。
3. MAPPED 复用 sample_id；填写完整原图到 sample_id 的表，或选择 UTF-8 CSV，列为 `source`（HDR绝对路径）及 `sample_id`。覆盖训练与测试全部图，不能只交部分图。CSV 和路径由本地固定表单处理，不发给模型。
4. 核对最低有效观测数（默认100），保存定义并生成报告。结果包括实物总数、训练／测试纳入数与排除数、逐实物表、排除列表，以及与像元指标并列的 accuracy、macro-F1、混淆矩阵。
5. HTML 和 ZIP 导出自动附上当前派生报告。ZIP 增加 `sample_evaluation.json`，保留原训练产物；未声明时导出结构保持原样。

## 固定算法与边界

- 同一实物的所有图像观测合并后投预测多数票，不做两级投票；PLS 响应不解释成概率。
- 真值必须唯一，不通过投票选择真值。同实物跨图或同图内保存真值不一致时标记 `truth_conflict`，排除出指标，保留冲突计数。
- 预测平票标记 `tie`；有效观测少于 N 标记 `insufficient`。所有原因可重叠展示，不任意选最小标签。
- 同一实物跨训练与测试标记 `split_overlap` 并排除；这不能修复原实验划分，也不能把原分数变成独立测试分数。
- 已声明但没有保存观测的原图也列入报告，标记 `truth_unavailable` 和 `insufficient`，不静默消失。
- macro 指标与原实验一致：只对纳入真值中出现的类别宏平均。无可用实物时指标未定义，不显示0分。
- `MIXED` 只有“不适用”说明，不输出整图或实物类别分数；用户错误声明 IMAGE 时，保存真值冲突仍会被排除，但系统无法从光谱自动识别物理场景。

历史报告依据逐观测预测、真值、来源派生，不重新读原图。这里的有效观测已经经过质量筛选、步长或训练抽样，**不是全部前景像元**；未保存的区域无法做完整真值一致性校验。报告明确标出这一限制。NPZ 的分组字段不能证明实物语义，第一阶段不支持 NPZ 实物报告；缺来源或预测的历史记录不能猜测补齐。

## 持久化与验收

定义、报告、revision、表单回执及输入产物摘要单独存入 SQLite `experiment_sample_evaluation`。变更使用 revision 原子校验，旧卡片不能覆盖新定义。读取和生成校验原预测、来源、配置及原指标的 SHA-256；报告和模型文件不被覆写。重开会话可重新读取，不自动生成或重训。

对话工具为 `experiments.sample_evaluation_get/update`；固定表单命令不依赖外部模型聊天服务。工具摘要只包含标量及不透明原图引用，完整逐实物表通过既有本地结果接口读取。自然语言工具规划仍依赖可用模型。

测试覆盖：多图合并投票、真值冲突、平票、100边界、无观测、跨训练测试、混合场景、流式来源解析、完整CSV、NPZ拒绝、归档校验、持久化、修订冲突、离线表单、自然语言路由、只读导出与保存产物不变。

后续第二阶段才把显式 `evaluation_target: sample` 接入新 Study 的折内评分与排序；必须重新计算候选，并与历史观测级排名隔离，不能从旧汇总分数换算。第一阶段报告不宣称已完成实物级选优。

实物定义同时支持写入实验 `config.sample_evaluation`，报告表单默认继承；MAPPED 可显式复用完整已确认的逐图 sample_id 表，禁止将缺省 HDR 路径或 batch 解释为实物编号。新选优来源保留 `study_selection`（任务、划分组类型、评价目标、评分口径及训练定义摘要）。报告覆盖后与摘要不一致时，表单和导出都会提示原排名不代表新口径。已保存报告的用户声明可用于后续 Study 配置继承，该读取只查声明，不读取留出集预测。

验证命令：`python -m pytest tests/test_sample_evaluation.py tests/test_experiment_results.py tests/test_experiment_conversation.py tests/test_agent_router.py -q`、`node --test tests/*.test.mjs`、`npm run build`。Windows 全套回归建议用仓库内专用短临时目录（例如 `--basetemp=.tmp-sample-suite`），避免 UUID 归档路径叠加默认用户临时目录后超过传统路径长度限制；该目录由 pytest 管理，不可指定已有数据目录。
