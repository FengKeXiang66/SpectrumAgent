# 回归未标注新数据推理

## 结论与范围

问题成立：原推理入口在判断模型协议前就强制查询标注与预处理运行，未标注的新 ENVI 无法到达冻结变换。仅把工具字段设为可选不能闭环，数据库 NOT NULL、已有结果查询的关联核对、Rust 转发、桌面选择项及对话路由也需要同步修改。

1a/1b/1c 已先提交为本地基线 `33dfd60`。在该基线上，用已注册训练快照模型和新导入、没有标注及处理记录的 ENVI，复现 `VERSION_CUBE_MISMATCH`。随后修复，保留该用例作为回归测试。

## 使用方式

1. 导入新的 ENVI，选择未标注，不必创建标签或制作标注。
2. 在对话中指定已注册回归模型及待预测数据。例如：“使用回归模型……对新数据……预测，应用模型保存的训练状态。”
3. `modeling.infer` 对训练快照模型只需要 `model_id` 和 `cube_id`；原生数值执行确认继续保留。
4. 输出像素响应图、适用性图、整图像素描述统计及整图均值谱预测。使用 `modeling.inference` 查询已完成结果。

整图没有隐含的目标物掩膜，也没有新数据真值。整图均值包含背景，不能解释为目标物含量或新批次准确率。像素预测继续沿用“训练粒度为样品均值谱，像素响应只表示空间趋势”的说明。

需要限定区域时，可显式传入真实保存的 `annotation_version_id`。训练快照模型不再要求为该掩膜生成预处理运行；若同时提供 `preprocess_run_id`，仍检查它与数据集、标注及当前状态的绑定。错误引用不会被自动丢弃并退化为整图。

## 协议边界

| 模型状态 | 无标注、无 run | 真实标注、无 run | 显式标注和 run |
| --- | --- | --- | --- |
| 完整 training_snapshot | 整图预测 | 按已标前景统计 | 核对绑定后按已标前景统计 |
| 历史 registration_reconstruction | 拒绝 | 拒绝 | 保留原校验与执行方式 |
| 新协议缺快照、来源不完整或身份不匹配 | 拒绝 | 拒绝 | 拒绝 |

所有路径继续校验实际输入波段数、波长轴校验值、冻结配方／拟合步骤、模型维数和适用范围。训练快照必须通过 `check_provenance`，协议及 `training_run_id` 必须与注册模型一致。预测数据不参与拟合。

## 记录与兼容

- REST、AI 工具和 Rust 的两个旧输入引用允许省略或 null；标识验证与固定转发路由保留。
- `inference_run` 的两个引用允许 NULL；保留真实旧行、产物行、唯一约束与外键，迁移可重复执行。run 非空时仍要求标注非空。
- 新推理记录的 stats 保存 `statistics_scope`、输入 HDR／数据文件 SHA256、波长轴校验值、实际模型标定 SHA256 与训练协议。读取前后核对输入文件，变化时不登记成功结果。
- `state.npy` 保存实际统计掩膜，并与像素预测和图像产物一同校验；无标注时整图参与统计。
- 为兼容原客户端，`n_foreground` 字段保留：整图模式表示参与统计的全部像元。界面改称“参与统计的像素数”，同时显示统计范围。
- 回归模型标识与近期原生回归操作走原生推理工具。明确指定的其他模型优先，不让近期回归操作覆盖另一个模型的推理入口。
- 未标注数据在推理后仍是未标注状态；推理不会生成标注或预处理记录。

## 验证与限制

`test_regression_new_inference.py` 覆盖真实 ENVI 的无标注新数据、同一模型对训练数据的预测、像素及均值谱与快照重放一致、推理不调用 fit、REST 可选引用、真实掩膜、不匹配波段／波长拒绝、快照来源与身份拒绝、原生对话执行和结果查询，以及迁移保留旧结果／产物／外键。旧路径在 `test_regression_pipeline.py` 中补验无引用拒绝及完整引用成功。

Rust 测试检查无引用、null 和真实标注三种固定请求，继续拒绝伪造代理路径及非法引用。前端测试检查新数据只发送模型与 cube，真实标注和历史引用仍显式发送。

最终检查：后端全量 `python -m pytest tests -q --tb=short --show-capture=no` 为 **215 passed、1 skipped**；使用正常本机权限覆盖 Windows DPAPI 临时假密钥测试。前端 `node --test --test-concurrency=1 tests/*.test.mjs` 为 **27 passed**；Rust `cargo test --offline models::tests` 为 **10 passed**；`npm run build` 与 `git diff --check` 通过。保留已有前端分包提示和测试弃用／单类指标警告，未影响通过结果。

测试对话使用脚本模型调用真实后端，未以此宣称外部模型的自然语言规划已实测。没有重新冻结 Python 后端或制作安装包；源码、前端构建和 Rust 测试不能替代安装版更新。
