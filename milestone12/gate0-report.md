口径：每类取各 cube 的类均值谱，类内 = 同类 cube 两两距离均值；类间 = 类质心两两距离；比值 = 最小类间 ÷ 平均类内。

## 3. 闸门 1：块级留一 cube 的 AUC

口径：
- 空间池化 **10×10 = 100 px**（≈ n=800 时的块大小 185 px 量级），模拟超像素均值谱
- 前景块 = 块内 ≥80% 像素属于该类；背景块 = 整块留白且距标注 >20 px
- 训练 = 其余 cube 的前景块质心；测试 = 留出 cube 的块
- 评分 = 与质心的余弦相似度；负样本 = 同 cube 的背景块

| 口径 | PE | PET | PP |
|---|---|---|---|
| SNV + 余弦 | 0.989 | 0.986 | **0.469** |
| 原始反射率 + 欧氏 | 1.000 | 0.973 | 0.780 |
| **原始反射率 + 余弦** | **0.988** | **0.988** | **0.801** |
| SNV + 一阶导 + 余弦 | 0.992 | 0.909 | 0.610 |

判据：≥0.95 开工 / 0.85–0.95 只做候选提示 / <0.85 转学习型。

逐 cube（原始反射率 + 余弦）：
- PE 0.972 / 0.994 / 1.000
- PET 0.988 / 1.000 / 0.977
- PP 0.859 / 0.940 / 0.714 / 0.689

**两个反直觉的发现**：
1. **SNV 害死 PP**（0.47 vs 0.80）。SNV 把亮度归一化掉，而 PP 与背景唯一的差别就是亮度。匹配器必须用原始反射率，不能用 SNV。
2. 单像元 AUC（PE 0.91 / PET 0.79 / PP 0.51）远低于块级——**必须块平均**。单像元信噪比：PE 2.3、PET 1.8、PP ≈ 1.0。
